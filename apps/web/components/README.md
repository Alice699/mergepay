# Components

Shared presentation belongs here. Product behavior stays in `features`, while protocol
logic stays in `packages/rialo-client`.

- `ui/` — framework-agnostic primitives;
- `layout/` — navigation and page composition;
- `wallet/` — wallet connection surfaces;
- `bounty/` — reusable bounty presentation;
- `feedback/` — loading, empty, error, and transaction states.
